## Issue tracker

For questions, bug reports, and feature requests, use the GitHub issue tracker for this project.

## Security reporting

Private security issues should not be filed in public. Please use the process documented in [SECURITY.md](SECURITY.md).

## Community expectations

Support is provided on a best-effort basis by the maintainers and the open-source community. Please be specific when reporting issues, and include browser version, operating system, and reproduction steps when possible.
