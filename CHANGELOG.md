# Changelog

All notable changes to this project will be documented in this file.

## Unreleased

- Initial project documentation and repository governance files added.

## 1.0.0

### Added

- Browser extension that converts text between English, French, and Arabic keyboard layouts.
- Automatic script detection and conversion direction suggestions.
- Copy and replace actions for selected text inside supported input contexts.
- Popup UI with quick conversion pairs and persistent layout settings.
- Conversion tests covering layout alignment, duplicate detection, and round-trip validation.
