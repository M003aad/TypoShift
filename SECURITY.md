# Security Policy

## Supported versions

The project currently supports the following version(s):

| Version | Supported |
| --- | --- |
| 1.0.0 | ✅ |
| < 1.0.0 | ❌ |

## Reporting a vulnerability

Please do not open a public issue for security-sensitive problems.

Use one of the following private channels:

- GitHub Private Vulnerability Reporting (preferred)
- Email: 188705139+M003aad@users.noreply.github.com

When reporting, include:

- a description of the issue and affected component
- the steps to reproduce or exploit it
- the impact and any known mitigations
- your preferred contact method for follow-up

## Response expectations

We aim to acknowledge valid reports within 5 business days and provide an initial assessment within 10 business days when possible.

For confirmed vulnerabilities, we aim to prepare and release a corresponding fix in a timely manner according to the severity and impact. Security fixes will be prioritized over non-security work where needed.

## Disclosure policy

We ask reporters to keep the issue private until a fix is available or a public disclosure is agreed upon. Public discussion should only happen after the maintainers have reviewed the report and coordinated a safe release.
